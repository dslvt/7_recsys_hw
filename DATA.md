# Данные MovieLens 100K

Из корня проекта выполните:

```sh
python3 -B prepare.py
python3 -B -m unittest discover -s tests -p test_data.py -v
```

Первая команда скачивает MovieLens 100K с сайта [GroupLens](https://grouplens.org/datasets/movielens/100k/), проверяет архив и сохраняет готовые файлы в `data/` рядом со скриптом. Вторая команда проверяет результат. Для повторного запуска интернет не нужен. Если исходный архив уже есть, укажите путь к нему:

```sh
python3 -B prepare.py --zip /path/to/ml-100k.zip
```

При ошибке проверки скачайте архив заново. Скрипт сам проверяет контрольную сумму. Вводить её вручную не нужно.

## Как разделены события

Каждая оценка считается событием, включая оценку в одну звезду. Скрипт сохраняет все 100 000 событий. Для каждого пользователя он сортирует их по времени. Если время совпадает, первым идёт фильм с меньшим числовым `item_id`.

Пусть `s` содержит фильмы одного пользователя в этом порядке. Предпоследний фильм оставляем для валидации, последний для теста. В тестовую историю входит предпоследний фильм, потому что пользователь уже оценил его к моменту запроса.

| Файл | Содержимое | Размер |
|---|---|---:|
| `train.json` | Для каждого пользователя список `s[:-2]` | 943 пользователя, 98 114 событий |
| `val.json` | Пары `[s[:-2], s[-2]]` | 943 запроса |
| `test.json` | Пары `[s[:-1], s[-1]]` | 943 запроса |
| `catalog.json` | Для каждого фильма список из 35 числовых признаков | 1682 фильма |

В файлах JSON ключи каталога и пользователей записаны строками. Сами истории содержат числовые идентификаторы фильмов. Обе проверочные выборки упорядочены по числовому идентификатору пользователя.

Для обучения TIGER берите каждый непустой префикс обучающей истории, после которого есть ещё один фильм. Всего получится 97 171 пара:

```python
for seq in train.values():
    for i in range(1, len(seq)):
        history, target = seq[:i], seq[i]
```

## Признаки фильма

Первые 19 значений обозначают жанры в порядке из `u.item`, включая `unknown`. Следующие 16 значений описывают слова из названия фильма. Скрипт переводит название в нижний регистр и выделяет фрагменты по шаблону `[a-z0-9]+`, включая год. Для каждого фрагмента он вычисляет `sha256(token).digest()[0] % 16` и ставит `1.0` в соответствующую ячейку. Остальные ячейки содержат `0.0`. Если два слова попали в одну ячейку, она по-прежнему содержит `1.0`. Оценки, даты оценок и популярность фильма в признаки не входят.

## Источник и условия использования

Данные собрала исследовательская группа GroupLens Миннесотского университета. Для ссылки на набор данных используйте публикацию F. Maxwell Harper и Joseph A. Konstan, *The MovieLens Datasets: History and Context* (2015).

Полные условия находятся в `ml-100k/README` внутри исходного архива. Каждый участник скачивает свою копию. Не выкладывайте исходные записи и подготовленные JSON в репозиторий. Для распространения данных и коммерческого использования нужно отдельное разрешение. При использовании укажите источник и не представляйте работу как одобренную авторами данных.
