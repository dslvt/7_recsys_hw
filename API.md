# Какие функции нужно реализовать

Напишите решение в `submission.py`. Выполняйте команды из корня проекта в окружении с Python 3.11:

```sh
python3.11 -m pip install -r requirements.txt
python3.11 -m pytest -q tests/test_public.py
python3.11 run.py --model baseline --data-dir data
```

Когда реализуете TIGER, запустите обучение и проверку:

```sh
python3.11 run.py --model tiger --data-dir data --seed 42 --epochs 1
```

Скрипт обучает модель на историях из `train.json` и по умолчанию проверяет её на валидации. Используйте `--split test` или `--split both` только после выбора параметров. Базовая модель сортирует фильмы по числу событий в обучающей выборке. При равной популярности первым идёт фильм с меньшим `item_id`. Уже просмотренные фильмы остаются в каталоге.

## Входные данные

В `catalog` ключом служит числовой `item_id`, значением служит список признаков фильма. Размерность признаков у всех фильмов одинаковая. Номера фильмов могут идти с пропусками. В `histories` каждая история представляет собой список числовых `item_id` в порядке событий. В файлах `val.json` и `test.json` каждая запись содержит историю и один целевой фильм. История может быть пустой. Подробнее о файлах написано в [инструкции по данным](DATA.md).

## Квантование и коды фильмов

`residual_quantize(x, codebooks)` принимает вещественные тензоры на CPU. Форма `x` равна `[N,D]`, форма словарей равна `[L,K,D]`. Начните с остатка `x`. На каждом уровне найдите для каждой строки ближайший вектор словаря по квадрату евклидова расстояния и вычтите его из остатка. При равном расстоянии выбирайте меньший индекс. Верните два тензора: индексы типа `torch.long` формы `[N,L]` и сумму выбранных векторов формы `[N,D]`.

`make_semantic_ids(item_codes)` получает словарь, в котором каждому числовому `item_id` соответствует кортеж индексов. В каждой группе фильмов с одинаковым кодом отсортируйте фильмы по `item_id`. Добавьте к коду номер фильма внутри группы, начиная с нуля. Если фильм в группе один, добавьте `0`. Верните словарь полных кодов с теми же ключами.

## Поиск

`beam_search(step, valid_ids, beam_size, k)` получает список разных допустимых кодов одинаковой ненулевой длины. Каждый код состоит из неотрицательных целых чисел. Начните с пустого кортежа `()` с оценкой `0`. Функция `step(prefix)` возвращает одномерный тензор оценок всех возможных токенов следующей позиции.

Сначала примените `log_softmax` ко всему тензору. Затем для каждого допустимого продолжения прибавьте полученное значение к оценке префикса. Объедините продолжения всех префиксов и оставьте до `beam_size` вариантов с наибольшей оценкой. При равенстве выбирайте лексикографически меньший кортеж. Верните в этом порядке до `min(k, beam_size, len(valid_ids))` полных кодов.

## Обучение и выдача

`TIGER(seed=42).fit(catalog, histories, epochs=1)` обучает на CPU токенизатор каталога и модель, которая предсказывает код фильма по истории. Сохраните соответствие между фильмами и полными кодами в обе стороны. Верните `self`. Внутреннее устройство классов можно менять.

`TIGER.recommend(history, k)` после обучения возвращает ровно `min(k, len(catalog))` разных числовых `item_id` в порядке убывания оценки. Поддержите пустую историю и неотрицательное `k`. Если результатов не хватает, повторите поиск с более широким лучом.

## Примеры для самопроверки

```python
import torch
from submission import TIGER, beam_search, make_semantic_ids, residual_quantize

x = torch.tensor([[1.0], [3.0]])
books = torch.tensor([[[0.0], [2.0]], [[0.0], [1.0]]])
codes, q = residual_quantize(x, books)
assert codes.tolist() == [[0, 1], [1, 1]]
assert q.tolist() == [[1.0], [3.0]]
assert make_semantic_ids({9: (4,), 2: (4,), 5: (1,)}) == {
    2: (4, 0), 9: (4, 1), 5: (1, 0)}

logits = {(): [0., 0.], (0,): [0., 8.], (1,): [0., 0.]}
assert beam_search(lambda p: torch.tensor(logits[p]), [(0, 0), (1, 0)], 2, 2) == [
    (1, 0), (0, 0)]

model = TIGER().fit({2: [0.0], 9: [1.0]}, [[2, 9], [9, 2]])
assert sorted(model.recommend([], 10)) == [2, 9]
```

Для оценки Recall@10 засчитайте попадание, если целевой фильм вошёл в десятку. Для NDCG@10 попадание на место `r` даёт `1/log2(r+1)`, считая места с единицы. Пропуск даёт ноль по обеим метрикам. Усредните результаты по всем запросам выборки. Для пустой выборки скрипт возвращает нули.
